# מצב טלפון — לנקות את הטלפון מתוך הטלפון עצמו

בלי מחשב ובלי כבל. מתקינים **Termux** (טרמינל לאנדרואיד) על הטלפון, ומחברים את ה‑adb של הטלפון **לעצמו**
דרך "ניפוי באגים אלחוטי". תפריט מודרך מריץ את אותם סקריפטים עם אותה רשימת הגנה.

> **למי זה מתאים:** אנדרואיד 11 ומעלה, ו‑Wi‑Fi פעיל לאורך כל העבודה.
> **מה שונה מהדרך עם מחשב:** אין Claude Code שמסביר ושואל — יש תפריט פשוט. התפריט **באנגלית בכוונה**, כי
> Termux לא מציג עברית מימין לשמאל נכון (למיטב ידיעתי). ההסברים כאן בעברית.
> **מגבלה חשובה:** אם משהו ישתבש (למשל מסך נעילה), אין מחשב נוסף לשחזר ממנו. לכן עובדים בקבוצות קטנות ובודקים
> אחרי כל אחת. מומלץ מאוד לעשות את זה קודם על טלפון ישן או משני, ולא על הטלפון היחיד שלכם.

## התקנה (פעם אחת)

1. **התקינו את Termux מ‑F‑Droid** ([f-droid.org](https://f-droid.org)), לא מ‑Google Play (שם הגרסה לא מתעדכנת).
2. פתחו את Termux והריצו:
   ```bash
   pkg update
   pkg install android-tools git
   git clone https://github.com/arielgalil/cleanmyandroid.git
   cd cleanmyandroid
   ```
3. הפעילו **אפשרויות מפתחים**: הגדרות ← אודות הטלפון ← הקישו 7 פעמים על מספר Build
   (סמסונג: מידע על תוכנה; שיאומי: גרסת OS).
4. שיאומי/רדמי/פוקו בלבד: הפעילו גם **ניפוי באגים ב‑USB** ו‑**ניפוי באגים ב‑USB (הגדרות אבטחה)**
   (עשוי לדרוש חשבון Mi וכרטיס SIM).

## חיבור (בכל פעם שמתחילים)

1. התחברו ל‑**Wi‑Fi**.
2. אפשרויות מפתחים ← **ניפוי באגים אלחוטי** ← הפעילו.
3. פתחו חלון מפוצל או חלון צף כך ש‑Termux וההגדרות נראים **יחד** (קוד ההתאמה פג כשסוגרים את החלון).
4. ב‑Termux: `bash phone-mode/menu.sh` ← בחרו **1**.
5. בהגדרות: ניפוי באגים אלחוטי ← **התאמת מכשיר באמצעות קוד התאמה**. יופיעו כתובת עם פורט (למשל
   `192.168.1.20:37215`) וקוד בן 6 ספרות. הקלידו ב‑Termux את **הפורט** ואת **הקוד**.
6. סגרו את חלון ההתאמה. במסך "ניפוי באגים אלחוטי" עצמו יש "כתובת IP ופורט" — **פורט אחר**. הקלידו אותו.
7. אם מופיע "לאפשר ניפוי באגים?" — סמנו "תמיד" והקישו **אפשר**.

## עבודה

| בתפריט | מה זה עושה |
|---|---|
| **2** | גיבוי מצב הטלפון (רשימות חבילות והגדרות) |
| **3** | ניקוי מודרך לפי היצרן שלכם: מראה את המועמדים, אתם מסמנים מה להשאיר, ואז קבוצות של 8. **אחרי כל קבוצה בודקים:** נעילה, שיחה, התראה מוואטסאפ/SMS, הגדרות. אם משהו לא עובד — עונים `n` והקבוצה חוזרת מיד |
| **4** | אחרי עדכון מערכת או אתחול: מה חזר, ואפשר להשבית שוב |
| **5** | להחזיר הכול, אפליקציות מסוימות, או את ה‑DNS הפרטי |
| **6** | סיום: מכבה ניפוי באגים ואפשרויות מפתחים, כדי שאפליקציות הבנק יעבדו |

אחרי קבוצה אחרונה חכו **15 שניות** לפני אתחול. את ההגדרות הידניות (מזהה פרסום, MSA ועוד) עושים לפי
[docs/settings-toggles.md](../docs/settings-toggles.md).

## מה מוגן
אותה רשימת הגנה כמו בדרך עם מחשב: התרעות פיקוד העורף (Cell Broadcast), VoLTE ו‑IMS, שיחות ו‑SMS, מקלדת, מסך נעילה,
חשבון היצרן, Play Services. התפריט מציג רק מועמדים בטוחים מתוך `examples/<יצרן>/starter.txt`. חבילות שמסומנות
שם ב‑`#` נשארות פעילות.

## תקלות
- **"adb: no devices"** — ניפוי אלחוטי כבה (Wi‑Fi נפל או האתחול). הפעילו שוב ובחרו 1 מחדש (פורט חדש בכל פעם).
- **Termux נסגר ברקע** — באנדרואיד 12 ומעלה המערכת עלולה להרוג תהליכי רקע. השאירו את Termux על המסך, ואם
  החיבור נפל: `adb kill-server` ואז חיבור מחדש (למיטב ידיעתי; לא נבדק על כל יצרן).
- **פורט או קוד שגויים** — שמרו את חלון ההתאמה פתוח בזמן ההקלדה.
- **באנדרואיד 17** הסרה (Uninstall) של אפליקציות מערכת נחסמת. התפריט משתמש רק בהשבתה, שעדיין עובדת.
- עוד: [docs/TROUBLESHOOTING.md](../docs/TROUBLESHOOTING.md).
