# הגדרות פרטיות ופרסומות — בלי מחשב

את אלה עושים ביד בטלפון, לפני או אחרי הכיבוי ב‑adb. שמות התפריטים משתנים בין גרסאות — אם לא מוצאים, חפשו
בשורת החיפוש של ההגדרות.

## כל טלפון עם שירותי Google
- **מחיקת מזהה הפרסום:** הגדרות ← אבטחה ופרטיות (או Google) ← פרטיות ← **מודעות** ← **מחיקת מזהה הפרסום**.
- **נתוני שימוש ואבחון:** הגדרות ← Google ← ⋮ ← **שימוש ואבחון** ← כיבוי.
- **מיקום:** הגדרות ← מיקום ← שירותי מיקום ← כיבוי "סריקת Wi‑Fi" ו"סריקת Bluetooth" (אם לא צריך).

## סמסונג
- **Customization Service:** הגדרות ← אבטחה ופרטיות ← פרטיות נוספת (או "שירותים נוספים") ←
  **Customization Service** ← כיבוי / התנתקות.
- **פרסומות במסך הנעילה (Glance / "סיפורי מסך נעילה"):** הגדרות ← מסך נעילה ← כיבוי, אם קיים.
- **Samsung Free:** החליקו ימינה ממסך הבית ← כבו בהגדרות מסך הבית.
- **התראות שיווק:** Galaxy Store ← תפריט ← הגדרות ← כיבוי "התראות על מבצעים".

## שיאומי / רדמי / פוקו
- **ביטול הרשאות MSA:** הגדרות ← סיסמאות ואבטחה (HyperOS: טביעות אצבע, זיהוי פנים ונעילת מסך) ←
  **הרשאה וביטול** ← **msa** ← חכו כ‑10 שניות ← **בטל**.
- **"המלצות פרסומות מותאמות אישית":** כבו בתוך ההגדרות של כל אפליקציית מערכת — אבטחה, מנהל קבצים, מוזיקה,
  ערכות נושא, הורדות, GetApps.
- **Wallpaper Carousel / קרוסלת טפטים:** הגדרות ← מסך נעילה ← כיבוי.
- **תיקיות "המלצות":** לחיצה ארוכה על תיקייה במסך הבית ← כיבוי "אפליקציות מקודמות".

## וואנפלוס / אופו / ריאלמי
- **ריאלמי:** הגדרות ← הגדרות נוספות ← **קבלת המלצות** ← כיבוי.
- כבו "המלצות" ב‑App Market, ב‑Themes וב‑Phone Manager (בהגדרות של כל אחת).
- **מגזין מסך נעילה / Glance:** הגדרות ← מסך נעילה ← כיבוי.

## מוטורולה
- **Glance:** הגדרות ← תצוגה ← מסך נעילה ← Glance ← כיבוי.

## Nothing
- **Lock Glimpse:** הגדרות ← מסך נעילה ← Lock Glimpse ← כיבוי (אם קיים).

## ויוו / iQOO
- **מגזין מסך נעילה:** הגדרות ← מסך נעילה ← כיבוי. בחנות V‑Appstore: הגדרות ← כיבוי התראות מבצעים.

## DNS שחוסם פרסומות (אופציונלי)

**הגדרה:** הגדרות ← חיבורים/רשת ← **DNS פרטי** ← "שם מארח של ספק DNS פרטי" ← `dns.adguard-dns.com` ← שמירה.

| יתרונות | חסרונות |
|---|---|
| חוסם פרסומות ומעקב באפליקציות ובאתרים רבים | **לא** חוסם פרסומות ביוטיוב |
| עובד גם ב‑Wi‑Fi וגם בנתונים | ספק ה‑DNS רואה לאילו אתרים הטלפון פונה |
| בלי אפליקציה | דפי התחברות ל‑Wi‑Fi ציבורי (מלונות, שדה תעופה, אוטובוסים) לא ייפתחו |
| | עלול להתנגש עם VPN; קישורים מסוימים בפרסומות/מיילים לא ייפתחו |

**כש‑Wi‑Fi ציבורי לא נפתח:** החזירו ל"אוטומטי", התחברו, והחזירו. **ביטול מלא:** DNS פרטי ← **אוטומטי**,
או `tools/restore.sh --dns`.
